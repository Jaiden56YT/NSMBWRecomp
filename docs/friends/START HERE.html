NSMBW Online

New Super Mario Bros. Wii with the nsmbw-project mod: up to 8 players, each on their own computer (Windows or Mac, mixed is fine). Do the one-time setup once, then pick what you're doing today.

One-time setup

  1. Put your game in the disc folder

    You need your own copy of the game, dumped from your disc. In Dolphin: right-click the game → Properties → Filesystem → right-click Disc → Extract Entire Disc… and choose the disc folder next to this page.

    When it's done, disc holds two folders: sys and files.

  2. Join the group's network (ZeroTier)

    Get ZeroTier free from zerotier.com/download. Open its icon (menu bar on Mac, tray on Windows) → Join New Network and paste the Network ID your host sends you. The host then ticks Auth next to you on my.zerotier.com; until then you can't connect.

    Using Hamachi instead? Get it from vpn.net, Network → Join an existing network with the name and password, and wait for a green dot. ZeroTier ran smoother in our tests.

  3. Open the game once

    Windows: double-click NSMBWCompiled.exe. When Windows asks about the firewall, click Allow and tick Public networks too (ZeroTier and Hamachi count as public).

    Mac (Apple Silicon): open Terminal, type xattr -dr com.apple.quarantine (with a space at the end), drag this whole folder onto the Terminal window and press Return. Then double-click NSMBW Online.app. If macOS still says it can't be opened, go to System Settings → Privacy & Security and click Open Anyway. Allow incoming connections if it asks.

    The very first time you may see “Preparing graphics” for up to half a minute. That only happens once.

  4. Set your controls

    Press F10 → Controls and set your keyboard keys or controller. Keep Graphics → Frame interpolation on Off (60 fps) for online play.

Playing

  1. Open the Online screen

    On the file-select screen choose Online (or press F10 → Online), then Join a room.

  2. Type the host's address

    The host sends you something like 10.67.48.65:47100 (ZeroTier) or 25.1.2.3:47100 (Hamachi). Type or paste it (Ctrl+V) and press Join.

  3. Wait for the host

    When the host presses Start, your game restarts by itself. That's normal.

  4. Join with your character

    On the players screen, press your confirm button to join. Then play! Players 5-8 use their normal controls too (the game sees them as GameCube controllers; nobody needs one).

  1. Make a room

    On the file-select screen choose Online (or F10 → Online), then Host a room.

  2. Send your address

    ZeroTier: send everyone your ZeroTier address (shown in the ZeroTier app or in the network's Members list, e.g. 10.67.48.65) with :47100 after it. Hamachi: the screen shows “… or Hamachi 25.x.x.x:47100”; send that one.

  3. Start

    When everyone is listed, press Start the game. Every game restarts together.

  4. Pick the file and players

    You choose the mode, the save file and the number of players, like normal. Your friends press confirm on the players screen to join.

Good to know
  • If someone's game hitches, everyone waits a moment (“Waiting for player N…” in the title bar).
  • Leaving (F10 → Online → Leave the session) or closing the window ends the game for everyone. The host can open a new room.
  • Progress made online isn't copied back to the host's normal save yet.
  • Everyone must use this same version of the game (the Windows and Mac downloads from the same day go together). A different version is turned away with “That room runs another version of the game”.

Something not working?

“No answer from that address”

Check you're both on the same ZeroTier network and approved (Auth ticked), or that the host has a green dot in Hamachi; that you typed the host's ZeroTier or Hamachi address; and that the host allowed the game through the firewall.

The game says it can't find the game files

The disc folder must contain sys and files directly (not another folder with them inside).

“Player N stopped responding”

Their connection dropped for 20 seconds. Check ZeroTier or Hamachi, then the host opens a new room.
